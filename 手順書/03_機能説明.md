# 機能説明（管理者向けの詳しい版）

ボタンを押すだけの利用方法は [使う人向けの目次](使う人向け/README.md) に分けています。ここでは、各機能が何をするものかを管理者向けに説明します。

## Bot本体

`main.py` は `.env` を読み込み、Botを起動します。`cogs/` 直下のPythonファイルと、サブフォルダー内の `vc_main.py` を自動で拡張機能として読み込みます。

`GUILD_ID` が設定されている場合は対象サーバーへ即時同期し、未設定の場合はグローバル同期します。`cogs/` のPythonファイルを変更すると、`watchfiles` により再ロードとコマンド再同期が行われます。

## 自動ロール

`auto_role.py` の `on_member_join` が新規参加を検知し、`DEFAULT_ROLE_ID` のロールを付与します。ロールが存在しない、またはBotの権限・ロール順位が不足している場合はログにエラーを出します。

## 専用ロール（`/myrole`）

| コマンド | 内容 |
|---|---|
| `/myrole create` | 基準ロールの直下に専用ロールを作成し、作成者へ付与 |
| `/myrole add_member` | 作成したロールを指定メンバーへ付与 |
| `/myrole remove_member` | 指定メンバーからロールを解除 |
| `/myrole edit` | ロール名・色を変更 |
| `/myrole delete` | 作成したロールを削除。管理者も実行可能 |

基準ロールは `BASE_ROLE_ID` を優先し、見つからない場合は `---この以下自動ロール---` という名前を検索します。

## プライベートVC

ポータルの「自分のルーム作成」から通常または非表示のVCを作成します。作成者はオーナーとして、チャンネル管理・メンバー移動などの権限を持ちます。

管理パネルでは、部屋の保存、鍵の開閉、表示・非表示、ロール招待・解除、参加者へのDM、モデレーター設定、オーナー譲渡を操作できます。

通常のVCは `CREATE_CHANNEL_ID` への入室でも自動作成されます。空になった部屋は、保存されていなければ自動削除されます。

操作パネルは、ポータルのボタン、`!vc`、`/vc panel` から表示できます。
