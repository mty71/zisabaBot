# セットアップ手順（サーバー管理者向け）

このページはBotをサーバーへ設置する人向けです。普段の使い方だけを知りたい場合は、先に [使う人向けの目次](使う人向け/README.md) を読んでください。

## 1. 必要なもの

- Python 3.10以降を推奨
- Discordサーバー
- Discord Developer Portalで作成したBot
- Botを実行するWindowsまたはLinux環境

## 2. パッケージをインストールする（初回だけ）

プロジェクトのルート（`main.py` がある場所）で実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 3. Botの設定を作る

`.env.example` を `.env` としてコピーし、[環境変数](02_環境変数.md) を設定します。

```powershell
Copy-Item .env.example .env
```

`DISCORD_BOT_TOKEN` は必須です。トークンはこのファイル以外へ記載せず、Gitへコミットしないでください。

## 4. Discord側でBotを許可する

Developer PortalのBot設定で、次のPrivileged Gateway Intentsを有効にします。

- Message Content Intent
- Server Members Intent

Bot招待時には、少なくともロール管理、チャンネル管理、メンバー移動、メンバーのミュート・スピーカー抑制、メッセージ送信、埋め込みリンク、メッセージ履歴の閲覧を許可します。

Botのロールは、Botが作成・編集するロールより上位に配置してください。

## 5. Botを起動する

```powershell
python main.py
```

正常に起動すると、ロードしたCogとスラッシュコマンド同期結果がログに出ます。

## 6. サーバーで最初に行うこと

1. 管理者が `!setup_portal` を実行する
2. 投稿されたポータルのボタンからVC作成を確認する
3. 必要に応じて `!vc` または `/vc panel` で操作パネルを確認する
4. 新規参加者へのロール付与を使う場合、`DEFAULT_ROLE_ID` を設定して確認する
