# 環境変数

設定ファイルはプロジェクト直下の `.env` です。

| 変数 | 必須 | 用途 |
|---|---|---|
| `DISCORD_BOT_TOKEN` | 必須 | Discord Botの認証トークン |
| `CREATE_CHANNEL_ID` | VC機能で必須 | 入室すると自動VCを作成するボイスチャンネルのID |
| `CATEGORY_ID` | VC機能で必須 | 作成したVCを配置するカテゴリのID |
| `COMMAND_PREFIX` | 任意 | テキストコマンドの接頭辞。既定値は `!` |
| `GUILD_ID` | 任意 | スラッシュコマンドを特定サーバーへ同期するID。未設定時はグローバル同期 |
| `DEFAULT_ROLE_ID` | 自動ロールで必須 | 新規参加者へ付与するロールのID |
| `BASE_ROLE_ID` | 専用ロール・招待で推奨 | 基準となる仕切りロールのID |
| `DEBUG_MODE` | 任意 | `True` でデバッグログを有効化。既定値は `False` |
| `LOG_TO_FILE` | 任意 | `True` で `logs/bot.log` に保存。既定値は `False` |

## IDの取得

Discordの開発者モードを有効にして、対象のサーバー・チャンネル・カテゴリ・ロールを右クリックし、「IDをコピー」を使用します。

## 設定例

```dotenv
DISCORD_BOT_TOKEN=ここには実際のトークンを設定
CREATE_CHANNEL_ID=123456789012345678
CATEGORY_ID=123456789012345678
COMMAND_PREFIX=!
GUILD_ID=123456789012345678
DEFAULT_ROLE_ID=123456789012345678
BASE_ROLE_ID=123456789012345678
DEBUG_MODE=False
LOG_TO_FILE=True
```

上記のトークンやIDは例です。実際の値をリポジトリへ公開しないでください。
