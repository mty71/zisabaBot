# 運用とトラブルシューティング

## Botが起動しない

- `DISCORD_BOT_TOKEN` が空でないか確認する
- `python -m pip install -r requirements.txt` を実行する
- `DEBUG_MODE=True` にしてログを確認する
- トークンを再発行した場合は `.env` を更新する

## スラッシュコマンドが表示されない

- `GUILD_ID` が正しいか確認する
- 起動ログのコマンド同期結果を確認する
- グローバル同期は反映に時間がかかるため、開発時は `GUILD_ID` の設定を推奨する

## ロールが付与・作成できない

- Botのロールを対象ロールより上位へ移動する
- 「ロールの管理」権限を付与する
- `DEFAULT_ROLE_ID`、`BASE_ROLE_ID` が正しいか確認する
- 基準ロールが削除されていないか確認する

## VCが作成されない

- `CREATE_CHANNEL_ID` が作成用VCのIDか確認する
- `CATEGORY_ID` が存在するカテゴリのIDか確認する
- Botにチャンネル管理権限があるか確認する

## DMが届かない

受信者がサーバーDMを拒否している場合、Discordの仕様上送信できません。パネルには成功数と失敗数が表示されます。

## 再起動後にVCパネルが動かない

- `data/vc_data.json` のJSONが壊れていないか確認する
- 保存対象VCが実際に存在するか確認する
- Botが対象チャンネルを管理できるか確認する

## 停止方法

コンソールで `Ctrl+C` を入力します。終了処理でBotを閉じ、保持中のVCデータを保存します。
