# 使う人向けの使い方

ここは、BotをDiscord上で使う人だけの説明書です。Python、コード、インストール、環境変数の知識は必要ありません。

## 機能別の説明

### ボイスチャットを使う

[プライベートVCの使い方](01_プライベートVC.md)

部屋の作成、保存、鍵、非表示、招待、モデレーター、オーナー変更を説明します。

### 自分専用のロールを使う

[専用ロールの使い方](02_専用ロール.md)

自分のロールを作る、メンバーへ付ける、外す、名前や色を変更する、削除する方法を説明します。

### 操作できない時

[困ったとき](04_困ったとき.md)

ボタンやコマンドが使えない時に、管理者へ伝える内容を説明します。

Botがサーバーに設置されていない場合や、ボタンが動かない場合は、サーバー管理者へ連絡してください。
