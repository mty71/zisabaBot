# 専用ロールの使い方

スラッシュコマンド入力欄で `/myrole` と入力すると、利用できる操作が表示されます。

## ロールを作る（`/myrole create`）

1. Discordのメッセージ入力欄に `/myrole create` と入力します。
2. 「name」に作りたいロール名を入力します。
3. 「color_code」に色を入力します。
4. 送信します。

色は次のどちらかで指定できます。

- `#FF0000` のようなカラーコード
- `RED` などのDiscordの色名

色を省略した場合は、標準の色になります。作成したロールは自分に付きます。

### 例

```text
/myrole create name: イベント参加者 color_code: #00FF00
```

作成できない場合は、Botのロール権限やサーバーの設定が必要な可能性があります。サーバー管理者へ連絡してください。

## メンバーへ付ける・外す

- `add_member`: 自分が作ったロールを他のメンバーへ付けます
- `remove_member`: 自分が作ったロールをメンバーから外します

操作するロールと対象メンバーを画面の候補から選んでください。

## 名前や色を変える

`edit` を選び、変更したい名前または色を入力します。色は `#FF0000` のようなカラーコードでも指定できます。

## ロールを削除する

`delete` を選び、削除するロールを選びます。削除したロールは元に戻せません。

自分が作ったロールだけを操作できます。ロールの候補が出ない場合は、サーバー管理者へ連絡してください。
