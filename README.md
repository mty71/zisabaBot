# zisabaBOT

Discordサーバー向けの管理Botです。現在の実装では、次の機能を提供します。

- 新規メンバーへのデフォルトロール自動付与
- ユーザーが作成・管理できる専用ロール
- ボタン操作で作成するプライベートボイスチャンネル
- VCの保存、鍵、表示、招待、モデレーター、オーナー譲渡
- VC関係者へのDM通知
- `cogs/` の変更を検知するホットロード
- コンソールおよび任意のログファイルへのログ出力

## 注意

- `.env` にはBotトークンが含まれるため、共有・公開しないでください。
- IDの設定を間違えると、ロール付与やVC作成が動作しません。
- Botのロールは、操作対象のロールより上位に配置してください。
- `data/vc_data.json` はプライベートVCの状態を保持します。削除・編集前にバックアップしてください。
